## 2. Conventions

- **Units/grid:** 1 tile = 1 world unit (`Config.tile`). Ground plane is x/z, **y is up**. Tile `(tx, tz)` covers `[tx, tx+1) x [tz, tz+1)`; center is `(tx+0.5, tz+0.5)`. Helpers: `Game.util.tileOf(v)`, `Game.util.tileCenter(i)`.
- **Facing:** characters face local **+z**; character's left side is **+x**. `rotation.y = atan2(vx, vz)` gives the heading for velocity `(vx, vz)`.
- **Camera yaw:** yaw 0 = camera at +z looking toward -z. Screen-up on the ground = `(-sin yaw, 0, -cos yaw)`, screen-right = `(cos yaw, 0, -sin yaw)` (`rig.getForward/getRight`).
- **Colors:** hex values are used as-is (no color management, r128 default). Author colors in display space.
- **Geometry:** every toon-shaded mesh needs a `color` vertex attribute (`Render.colorize` or `Models.mergeParts`). Materials use `vertexColors: true`. Normals are transformed with `modelMatrix` (uniform scale only; no non-uniform scale on toon meshes).
- **Fixed step:** simulation runs in `Loop.onUpdate` at `Config.loop.fixedStep` (1/60 s). Anything visual that moves should interpolate with `alpha` in `Loop.onFrame` (see player.js: store prev/curr, lerp).
- **Time of day:** hours `0..24` (float, wraps). **Season:** `'spring' | 'summer' | 'autumn' | 'winter'` or index 0..3.
- **Never** use localStorage keys outside the `togie-valley/` prefix (see Save schema).
- Code, comments, file contents in English.

## 3. Modules

### Game (core.js)
`Game.VERSION`, namespace object. All modules hang off it.

### Game.Config (core.js)
Plain tunables, mutate before `Display.init`/`Render.init` or at runtime where noted.
- `tile` (1)
- `loop`: `fixedStep` (1/60), `maxFrameDelta` (0.25), `maxSubSteps` (5)
- `display`: `maxDpr` (2), `minPixelRatio` (0.6)
- `scaler`: `enabled`, `targetFps` (60), `lowRatio` (0.82), `highRatio` (0.95), `interval` (1 s), `warmupWindows`, `minScale` (0.5), `maxScale` (1), `stepDown` (0.1), `stepUp` (0.05), `upAfterWindows`, `holdAfterDownWindows`
- `render`: `antialias`, `bands` [0.12, 0.52], `halftoneCell` (CSS px), `halftoneStrength`, `outlineWidth` / `outlineWobble` (CSS px), `wobbleFps` (8), `grain`, `grainSize`, `vignette`, `fogNear`, `fogFar`, `inkColor`, `shadowColor`, `shadowOpacity`, `vignetteColor` (read at `Render` load / `applyResolution`; most are re-applied on every resize)
- `camera`: `near`, `far`, `followLambda`, `yawLambda`, `presetLambda`, `zoomLambda`, `portraitBoost`, `zoomMin`, `zoomMax`, `presets.{outdoor,indoor}` = `{distance, pitch (deg), fov, lookHeight}`

### Game.util (core.js)
`clamp(v,lo,hi)`, `lerp(a,b,t)`, `damp(cur,target,lambda,dt)`, `smoothstep(e0,e1,x)`, `wrapAngle(a)`, `lerpAngle(a,b,t)`, `rng(seed)` -> `() => [0,1)` (mulberry32), `tileOf(v)`, `tileCenter(i)`.

### Game.Events (core.js) - event bus
- `on(name, fn, ctx?)` -> returns an unsubscribe function. `once(name, fn, ctx?)`. `off(name, fn?, ctx?)` (no `fn` = remove all for that name). `emit(name, payload?)`.
- Handlers are called as `fn(payload, name)`. Exceptions in handlers are caught and logged. `'*'` receives every event.
- **Naming:** `domain:event`, lowercase, colon-separated (`display:resize`, `player:moved`). Past tense / state for facts (`crop:harvested`, `time:hourChanged`); imperative for requests (`ui:open`, `save:request`). Payload is always a single plain object (or omitted). No DOM events through the bus.
- **Emitted so far:** `display:resize` `{width,height,aspect,dpr,scale,pixelRatio,reason}`; `loop:pause` / `loop:resume` `{reason}`; `render:contextlost` / `render:contextrestored`; `game:ready` `{stage}`.

### Game.Display (core.js)
- State: `canvas`, `width`, `height` (CSS px), `aspect`, `dpr`, `scale` (dynamic resolution scale), `pixelRatio` (= clamp(min(dpr, maxDpr) * scale)), `scaler` `{enabled, targetFps, fps}`.
- `init(canvas)` measures (no event). `info(reason?)` snapshot. `refresh(reason?)` re-measure + emit if changed. `setScale(s, reason?)` (quantized to 0.05, clamped to min/maxScale; emits `display:resize` with `reason`). `setTargetFps(n)` (set 30 on 30 Hz devices so the scaler does not over-reduce). `sample(dt)` is called by the loop.
- Resize/orientation/visualViewport events are debounced 60 ms.

### Game.Loop (core.js)
- State: `step`, `timeScale`, `simTime`, `realTime`, `frame`, `alpha`, `fps` (smoothed), `running`, `paused`.
- `onUpdate(fn(dt), priority=0)` fixed-step callbacks; `onFrame(fn(frameDt, alpha, realTime), priority=0)` per rendered frame. Lower priority runs first. Both return a remover. Callback errors are caught and logged.
- **Reserved frame priorities:** `900` = `Render.update` (camera rig, tints, shadows), `1000` = `Render.draw`. Game logic that moves objects must use priority `< 900`.
- `start()`, `stop()`, `pause(reason)`, `resume(reason)` (reason-counted; paused while any reason is active). Auto `pause('hidden')` while the tab is hidden; `pause('contextlost')` on WebGL context loss.
- Frame delta is clamped to `maxFrameDelta`; at most `maxSubSteps` fixed steps per frame, the backlog is dropped.

### Game.Render (render.js)
Pipeline per frame (`Render.draw`): clear -> sky quad (halftone gradient) -> world scene (toon + outline hulls + blob shadows) -> grain/vignette overlay quad. No render targets / post-processing FBOs. Fog is custom (in-shader), colored with the sky horizon color.

- Fields: `scene`, `camera` (PerspectiveCamera), `renderer`, `skyScene`, `overlayScene`, `time`, `uniforms` (shared uniform objects, see below), `rig`, `seasons` (names array).
- `init(canvas?)` creates the renderer, sky, overlay, hooks `display:resize`, registers frame callbacks (priority 900/1000). Throws if WebGL is unavailable.
- `update(dt)`, `draw()`, `stats()` -> `{calls, triangles, pixelRatio}`.
- **Materials**
  - `toonMaterial({color=0xffffff, seasonal=0, halftone=true, side=FrontSide})` -> ShaderMaterial. 3 light bands (`Config.render.bands`), ambient + one directional light, vertex colors x `color`, fog, 45-degree screen-space halftone dots inside the shade band only. `seasonal` (0..1) is how strongly the season tint/recolor applies.
  - `outlineMaterial(widthMul=1)`; shared instances are used by `addOutline`.
- **Geometry helpers**
  - `colorize(geometry, color|fn(x,y,z))` sets the `color` attribute.
  - `addSmoothNormals(geometry)` adds attribute `smoothNormal` (angle-weighted, welded by position).
  - `addOutline(mesh, thin=false)` adds an inverted-hull child mesh sharing the geometry (screen-space constant width, ~8 fps wobble). Auto-calls `addSmoothNormals`. `thin` = 60% width. Outline meshes are named `'outline'` and ignore raycasts.
- **Blob shadows:** `addBlobShadow(target, radius, opacity?, radiusZ?)` -> handle `{target, mesh, groundY, remove()}`. Follows target world x/z, shrinks/fades with height above `groundY` (default 0). Updated in `Render.update`.
- **Tints:** `setTimeOfDay(hours)` / `getTimeOfDay()` (sky, fog, ambient, light color + direction; set it as often as needed, it is cheap). `setSeason(nameOrIndex, instant=false)` / `getSeason()` (smooth blend inside `Render.update` unless `instant`).
- **Screen/world helpers** (client CSS px coords):
  - `screenToGround(clientX, clientY, groundY=0, out?)` -> `THREE.Vector3` or `null`.
  - `screenToTile(clientX, clientY, groundY=0)` -> `{tx, tz, x, z, cx, cz}` or `null`.
  - `worldToScreen(vec3, out?)` -> `{x, y, visible}`.
- **Shared uniforms** (`Render.uniforms`, each `{value}`): `uLightDir` (toward light), `uLightColor`, `uAmbient`, `uFogColor`, `uFogRange`, `uBands`, `uHalftone` (x cell device px, y strength), `uSeasonTint`, `uSeasonHue`, `uSeasonAmt`, `uResolution`, `uTick`, `uOutline`, `uInkColor`, `uSkyTop`, `uSkyHorizon`, `uShadowColor`, `uOverlay`, `uVigColor`. Custom materials should reference these objects (do not clone them) to stay in sync with time of day / season.

#### Game.Render.rig (camera rig)
Tilted top-down perspective camera, damped follow, smooth yaw.
- `follow(obj3d, snap=false)` / `unfollow()` / `setTarget(x, y, z, snap=false)`.
- `setYaw(rad, snap=false)`, `rotateBy(delta)`, `rotateStep(dir=+1)` (next/prev 90 degrees), `getYaw()`, `getYawTarget()`, `getForward(out?)`, `getRight(out?)`.
- `setPreset('outdoor'|'indoor', snap=false)` (smoothly tweens distance/pitch/fov/lookHeight), `setZoom(z, snap=false)` (clamped `zoomMin..zoomMax`), `snap()`.
- `update(dt)` is called by `Render.update`. In portrait (aspect < 1) distance is multiplied by `(1/aspect)^portraitBoost`.

### Game.Models (models.js)
- Materials: `material(name)` shared toon materials: `'char'`, `'prop'`, `'foliage'`, `'ground'`, `'flat'`.
- Builders: `part(geometry, color, pos?, rot?, scale?)`, `mergeParts(parts)` -> one non-indexed vertex-colored geometry (with `smoothNormal`). Geometry is cached per key inside models.js.
- `character(opts)` -> `{root, joints, attach, parts, shadow, anim, update(dt, speed), dispose()}`
  - opts: `skin, hair, shirt, pants, boots, belt, eyes` (hex), `hairStyle` (`'bun'|'short'`), `hat` (`null|'straw'`), `scale`, `shadow` (default true).
  - `joints`: `root, hips, spine, head, shoulderL, shoulderR, hipL, hipR` (Groups; pivots at the joint). `attach`: `hat, handL, handR, back` (empty Groups for items). Height about 1.0 unit (1.17 with hat), feet at y=0.
  - `update(dt, speed)`: `speed` in units/s drives idle/walk/run blending (walk about 2, run above about 3.3), phase advances with distance.
- `Models.Anim`: `KEYS`, `newPose()`, `reset(p)`, `idle(pose, t)`, `walk(pose, phase)`, `run(pose, phase)`, `blend(out, poses[], weights[])`, `apply(character, pose)`, `update(character, dt, speed)`. Pose values: radians, `*X` swing positive = forward, `armLZ/armRZ` positive = outward, `bob` in world units.
- `groundPatch(w, d, {seed, skirt=0.7, colorFn(tx,tz,rng)})` -> Mesh, tiles centered on the origin with edges on integers (`userData.bounds`). No outline.
- `tree({variant: 0 round | 1 pine, scale, rotationY, shadow})` -> Mesh (outline + blob shadow; `userData.dispose()`).
- `house({shadow})` -> Mesh, 3x3-tile footprint centered on its origin (place at `x.5, z.5` to align), door faces +z.
- `tileCursor(color?)` -> flat 1x1 highlight Mesh, initially invisible.
